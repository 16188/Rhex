# 每日60s 与今日星座运势

这个插件会从 Viki 官方按日期生成的静态 JSON 拉取“60 秒看世界”数据，并依次使用官方域名、jsDelivr、JSDMirror 三条线路。每日资讯成功后，插件会等待 10 分钟，再从 `https://api.suxun.site/api/constellation` 拉取十二星座今日运势并合并发布一篇帖子。若接口的 `today` 因时区仍是昨天，插件会自动尝试日期匹配的 `nextday`；两者都没有当天内容时，每小时复查一次。

当前能力：

- 后台配置自动发布开关、目标节点、发布账号、每日发布时间、时区、标题模板、帖子状态、默认标签
- 通过插件后台页手动“立即发布一次”
- 使用插件后台任务自我续期，不依赖站内 HTTP 接口发帖，直接走宿主 `context.posts.create()` SDK
- 记录最近运行结果、下一次计划时间、最近一次发布帖子 slug
- 数据源临时失败时自动重试；若定时时刻两个资讯源都尚未更新，当天每 15 分钟自动补发，成功后恢复次日定时
- 每日资讯发布后 10 分钟自动发布一篇十二星座今日运势
- 星座任务按日期去重，重启、重试和重复操作不会重复挂起同一天任务
- 后台可立即重新挂起今日星座运势测试任务，不会重复发布每日资讯；残留的旧任务 ID 不会阻止测试

注意事项：

- 自动发布依赖后台任务 worker 正常运行
- 星座运势沿用每日资讯的发布账号、目标节点、发布状态和标签
- 发布账号必须是系统内可正常发帖的有效账号
- 目标节点必须允许该账号发帖；如果节点有积分/等级/VIP/审核规则，仍会按宿主规则校验
- `publishStatus=AUTO` 表示跟随节点自己的审核设置；`PUBLISHED` 表示强制直发；`PENDING` 表示强制进入审核
